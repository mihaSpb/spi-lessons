# Подключение Wildberries к вашему агенту

**Как пользоваться:** откройте своего агента в рабочей папке, приложите этот файл
и напишите: «Прочитай инструкцию и проведи меня по подключению Wildberries».
Дальше агент ведёт вас сам.

---

## Что будет в конце

1. Агент видит ваш кабинет продавца: товары, цены, остатки, заказы, воронку
   продаж, расходы на рекламу и отзывы.
2. Токен лежит в `.env` вашей рабочей папки и не уезжает в репозиторий.
3. В папке появляется скилл `.claude/skills/wildberries/`, и вы спрашиваете
   человеческим языком: «что просело за неделю», «где реклама съедает маржу»,
   «на что заканчиваются остатки».

---

# ИНСТРУКЦИЯ ДЛЯ АГЕНТА

## Правила работы

1. **Сначала документация, потом код.** Wildberries меняет API часто: адреса
   доменов, лимиты, состав полей. Прочитай актуальную документацию на
   `dev.wildberries.ru` **до** того, как писать запросы, и скажи человеку, что
   именно изменилось против того, что описано здесь.
2. **Начинай с чтения.** Первые запросы — только те, что смотрят: товары,
   остатки, заказы, статистика. Ничего не меняем, пока человек не убедился, что
   всё работает.
3. **Цены и остатки — только после подтверждения.** Ошибка в цене на маркетплейсе
   стоит реальных денег. Перед любым изменением показать: что меняем, с какого
   значения на какое, по каким товарам, и дождаться «да».
4. **Токен не выводить в чат.**
5. Лимиты жёсткие. Если пришёл ответ о превышении — не долбить повторами,
   подождать и сказать человеку.

## Шаг 0. Окружение

```bash
pip install requests python-dotenv pandas
printf '.env\n.venv/\n' >> .gitignore
git check-ignore .env
```

## Шаг 1. Человек создаёт токен

Продиктуй ровно это:

1. Зайди в кабинет продавца на `seller.wildberries.ru`.
2. Нажми на профиль в правом верхнем углу → **Настройки** → **Доступ к API**.
3. Нажми **Создать новый токен**.
4. Дай имя, например `agent`.
5. Отметь категории доступа. Начни с чтения:
   - **Контент** — карточки товаров;
   - **Аналитика** — воронка продаж, отчёты;
   - **Статистика** — заказы, продажи, остатки;
   - **Цены и скидки** — понадобится позже, если будете менять цены;
   - **Продвижение** — если нужна реклама.
6. **Не включай** галочку «Только на чтение», если планируете менять цены. Если
   пока только смотрим — наоборот, включи: так безопаснее.
7. Создай и скопируй токен. Он показывается один раз и живёт полгода.

Запиши в `.env`:

```
WB_API_TOKEN=eyJhbGciOi...
```

Скажи человеку: «Записал. Токен действует полгода, потом нужно будет выпустить
новый — я напомню, когда запросы начнут отваливаться».

## Шаг 2. Проверка связи

Создай `scripts/wb_check.py`:

```python
import os, requests
from dotenv import load_dotenv

load_dotenv()
TOKEN = os.environ["WB_API_TOKEN"]
H = {"Authorization": TOKEN}

r = requests.get("https://common-api.wildberries.ru/ping", headers=H, timeout=30)
print(r.status_code, r.text[:200])
```

Если `200` — связь есть. Если `401` — токен неверный или истёк. Если `403` — не
выданы нужные категории доступа.

## Шаг 3. Что можно спрашивать

Разные задачи живут на разных адресах. Ориентиры на момент написания —
**обязательно сверь с документацией**:

| Задача | Куда обращаться |
|---|---|
| Карточки товаров, характеристики | контентное API, раздел «Контент» |
| Остатки на складах | статистика, раздел «Склад» |
| Заказы и продажи за период | статистика, разделы «Заказы» и «Продажи» |
| Воронка продаж: показы, переходы, конверсия | аналитика, `seller-analytics-api.wildberries.ru` |
| Расходы на рекламу | рекламное API, `advert-api.wildberries.ru` |
| Отзывы и вопросы покупателей | раздел «Отзывы» |
| Цены и скидки | `discounts-prices-api.wildberries.ru` |

Создай скрипты по мере надобности, начиная с воронки и остатков — они дают
человеку первые полезные ответы.

## Шаг 4. Первый полезный отчёт

Не ограничивайся выгрузкой. Собери человеку то, ради чего он это подключал:

> Отчёт за последние 14 дней: топ-10 товаров по заказам, у кого просела
> конверсия, где расходы на рекламу выше 30 процентов от выручки, что
> заканчивается на складах при стабильном спросе.

Покажи таблицей и добавь три вывода словами: что чинить первым.

## Шаг 5. Скилл в рабочей папке

```
.claude/skills/wildberries/
├── SKILL.md
└── scripts/
    ├── wb_check.py
    ├── wb_funnel.py     # воронка продаж за период
    ├── wb_stocks.py     # остатки
    └── wb_ads.py        # расходы на рекламу
```

`SKILL.md`:

```markdown
---
name: wildberries
description: Кабинет продавца Wildberries — товары, остатки, заказы, воронка продаж, реклама, отзывы. Триггеры — «что по продажам», «остатки», «воронка», «реклама на вб», «отзывы покупателей».
---

# Wildberries

## Быстрый путь

    python3 scripts/wb_check.py                  # жив ли токен
    python3 scripts/wb_funnel.py --days 14       # воронка за период
    python3 scripts/wb_stocks.py                 # остатки
    python3 scripts/wb_ads.py --days 14          # расходы на рекламу

## Ключи

WB_API_TOKEN в .env. Живёт полгода. При 401 — выпустить новый в кабинете:
Настройки → Доступ к API.

## Правила

1. Изменение цен, скидок и остатков — только после подтверждения человека,
   с показом «было → станет» по каждому товару.
2. Лимиты жёсткие. При ответе о превышении — пауза, а не повтор.
3. Данные о продажах не пересказывать по памяти: каждый раз запрашивать заново.
4. Прежде чем строить новый запрос — сверяться с текущей документацией
   dev.wildberries.ru, адреса и поля меняются.

## Типовые вопросы

- Что просело по конверсии за две недели и почему.
- Где реклама съедает больше 30 процентов выручки.
- Что заканчивается на складе при стабильном спросе.
- Какие отзывы за неделю требуют ответа.
```

Строка в главный файл правил:

```
Wildberries подключён. Инструкция — .claude/skills/wildberries/SKILL.md.
Использовать для вопросов о продажах, остатках, рекламе и отзывах.
Любые изменения цен — только с моим подтверждением.
```

## Шаг 6. Финальная проверка

Выполни сам:

> «Собери отчёт за две недели: топ товаров, где просела конверсия, где реклама
> в минус, что заканчивается на складе. Три вывода, что делать первым.»

## Типичные ошибки

| Что видно | Что делать |
|---|---|
| `401 Unauthorized` | токен истёк или скопирован не полностью, выпустить новый |
| `403 Forbidden` | не выдана нужная категория доступа при создании токена |
| `429 Too Many Requests` | превышен лимит, подождать и снизить частоту |
| Пустой ответ вместо данных | часть отчётов формируется асинхронно: сначала запрос на построение, потом получение результата |
| Цифры расходятся с кабинетом | данные обновляются с задержкой, а часть отчётов считается по другой методике — сверять период и метод |

## Безопасность

- Токен с правом записи позволяет менять цены на всех товарах. Если задача —
  только смотреть, выпускайте токен «только на чтение».
- Не хранить токен в коде и в переписке, только в `.env`.
- Если токен засветился в скриншоте или чате — удалить его в кабинете и создать
  новый, старый перестанет работать сразу.
